# Archived one-off run queues

Shell queues that chained specific September runs (fidelity ladder arms, thinking-budget
curve, request replay, SWE-rebench generation). They are kept because
`docs/design_changes.md` names them as the provenance of those runs. Several point at run
directories that exist only on the original machine, so they document what was run rather
than being meant to run again. Run them from the repository root.
